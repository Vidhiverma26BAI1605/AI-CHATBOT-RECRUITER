# AI-CHATBOT-RECRUITER


1. Project Overview

The AI Recruiter Chatbot is a Python-based conversational application designed to assist recruiters in collecting and organizing candidate information.

Instead of manually asking every candidate the same questions, the chatbot conducts a structured conversation and collects information such as name, qualifications, experience, skills, and job requirements.

The project demonstrates how a chatbot can be used to make the initial recruitment and information-collection process faster and more organized.


PROBLEM STATEMENT

Recruiters often spend significant time collecting basic information from candidates and checking whether they meet the requirements of a job.

This project aims to solve this problem by creating a chatbot that:

Asks candidates predefined questions.
Collects their responses.
Extracts important candidate information.
Organizes the information in a structured format.
Provides a simple conversational interface for initial screening

DATASET USED

This project does not require a large external dataset.

The chatbot uses a JSON file containing predefined questions and chatbot information. The candidate's responses are collected during the conversation and stored as structured information.

Example information collected:

Name
Email
Educational qualification
Years of experience
Technical skills
Job role
Job requirements
Additional information


METHODOLOGY

The chatbot follows a simple conversational workflow:

Start
  ↓
Ask Candidate Information
  ↓
Ask Qualification
  ↓
Ask Experience
  ↓
Ask Skills
  ↓
Ask Job Requirements
  ↓
Extract Responses
